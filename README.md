# Publi Marketing

Plataforma integral de marketing digital, contenido, fotografía, diseño, clientes y analítica para Publi Guapiles.

Este es un esqueleto mínimo de infraestructura (solo `/health`). La arquitectura completa (módulos, base de datos, stack definitivo) está en revisión — ver `docs/architecture.md` una vez aprobada.

## Correr localmente

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```
